# Mobiles-Sales-Dashboard | Power BI
Interactive Mobiles Sales Dashboard built using Power BI and Excel.

## Overview
This project is an interactive Mobile Sales Dashboard developed in Power BI to analyze mobile sales performance, customer purchasing behavior, and business trends. The dashboard provides dynamic insights using KPIs, charts, maps, and slicers for better decision-making.

## Tools Used
- Power BI Desktop
- Microsoft Excel
- Power Query
- DAX

## Key Features
- Total Sales KPI
- Total Quantity Sold
- Total Transactions
- Average Selling Price
- Monthly Sales Trend
- City-wise Sales Analysis (Map)
- Brand & Mobile Model Analysis
- Payment Method Analysis
- Customer Rating Analysis
- Month-to-Date (MTD) Report
- Same Period Last Year (SPLY) Analysis
- Interactive Filters (Brand, Model, Year, Month)

## Dashboard Pages
1. Dashboard Overview
2. MTD Report
3. Same Period Last Year Report

## Dataset
- Source: Microsoft Excel (.xlsx)
- Records: Mobile Sales Data
- Data cleaned and transformed using Power Query.
